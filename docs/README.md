This directory contains system documentation, operational guides, and archived migration records for MyManager.

- `MANUAL_OPERATIONS_CHECKLIST.md`: Post-audit operational procedures, secret rotation steps, and Nginx Proxy Manager setup.
- `archive/`: Historical planning and migration specifications preserved for reference.
  - `archive/CLAUDE.md`: Earlier AI assistant reference guidelines (superseded by GEMINI.md).
  - `archive/CLAUDE_HANDOVER.md`: Migration and handover summary from Phase 10 monorepo refactoring.
  - `archive/files-implement.md`: File sharing and manager technical specification.
  - `archive/files-session-handoff.md`: Handoff notes for file storage setup and SSD mount points.
  - `archive/mymanager-redesign-plan.md`: Comprehensive redesign roadmap and audit test logs.
  - `archive/legacy/`: Obsolete prototype scripts preserved from early versions.
